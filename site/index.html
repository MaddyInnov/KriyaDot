First run

    
New to KriyaDot? Start here

    
Install the desktop app, connect any AI provider (Groq, OpenAI, OpenRouter, Anthropic, Ollama…), and have your first agentic conversation in under five minutes. No account, no subscription.

    

      

        
🪟

        
Windows (.exe) — first run

        
    
          
  1. Install. Double-click KriyaDot_0.1.0_x64-setup.exe and follow the wizard. If SmartScreen says “unknown publisher”, click More info → Run anyway (alpha builds aren’t code-signed yet).
    2. 
          
  2. Launch. Open KriyaDot from the Start menu. You’ll land in Chat — the sidebar holds the six destinations: Chat, Bots, Workflows, Marketplace, Workspace, Activity.
    3. 
          
  3. Add your AI key (BYOK). Open Accounts & API keys (settings) and add any provider you like — Groq (free tier at console.groq.com), OpenAI, OpenRouter, Anthropic, OpenCode Zen — or point KriyaDot at Ollama running locally. Keys stay on your machine; they only go to the provider you chose.
    4. 
          
  4. Say hello. Type in Chat and pick a bot (try Scout). When the bot wants to run a tool, an approval card appears — approve or deny inline. Nothing runs without your say-so.
    5. 
          
  5. Make it yours. In Preferences: five themes, Simple/Pro modes, English + Hindi UI, and your 3D companion pet.
    6. 
        

      

      

        
🐧

        
Linux (.deb / AppImage) — first run

        
    
          
  1. Install the .deb. sudo dpkg -i KriyaDot_0.1.0_amd64.deb — or double-click it and open with Software Install. If it asks for missing packages, run sudo apt-get install -f.
    2. 
          
  2. …or go portable. Prefer no install? chmod +x KriyaDot_0.1.0_amd64.AppImage && ./KriyaDot_0.1.0_amd64.AppImage — runs from anywhere, leaves your system untouched. Needs the system WebKitGTK: sudo apt install libwebkit2gtk-4.1-0 on Debian/Ubuntu, sudo dnf install webkit2gtk4.1 on Fedora.
    3. 
          
  3. Launch. Find KriyaDot in your app menu. First screen is Chat; the sidebar holds the six destinations: Chat, Bots, Workflows, Marketplace, Workspace, Activity.
    4. 
          
  4. Add your AI key (BYOK). Open Accounts & API keys (settings) and add any provider — Groq (free tier), OpenAI, OpenRouter, Anthropic, OpenCode Zen, or local Ollama. Keys stay on your machine.
    5. 
          
  5. Say hello, then make it yours. Chat with a bot (approval cards gate every tool call), then pick your theme, mode, language and 3D pet in Preferences.

FAQ

    
No confusion, promise

    

      
Is KriyaDot free?
Yes. The apps are free and open-source (Apache-2.0). You only ever pay your own AI provider for model usage — and you can dodge that entirely with free local models via Ollama.

      
Do I need API keys?
Only if you want cloud models. Paste a key once under Accounts & API keys (Groq has a generous free tier; OpenRouter and OpenAI-compatible endpoints work too). Prefer zero keys? Point KriyaDot at local Ollama or a BYO-CLI engine instead.

      
Which download do I need?
Windows PC → the .exe. Linux PC → the .deb. Control your PC from your phone → Companion APK. Automate your phone from your PC → Phone Agent APK. Start with desktop + Companion.

      
Is my data private?
KriyaDot is local-first: your keys, chats, and files live on your machine. Keys are only ever sent to the model provider you chose — never to us. Approvals gate every sensitive tool call.

      
What does “alpha” mean?
v0.1.0-alpha is an early build: the full feature set is there, but expect rough edges. Back up anything important, and report bugs on GitHub — every report shapes the beta.

      
Where do I start after installing?
Open the user guide above: install → add a key (or Ollama) → create your first bot → run the Morning briefing workflow → pair your phone. Five minutes, end to end.

User guide

    
From zero to your first autonomous run in five steps.

    
    
      
  1. Install
    Grab the desktop app for your OS from GitHub Releases, or run the web console + API from source with npm install in apps/api and apps/web.
    2. 
      
  2. Add a provider key (BYOK)
    Open Accounts & API keys and paste your key — Groq, OpenRouter, or any OpenAI-compatible endpoint. Prefer local? Point KriyaDot at Ollama or a BYO-CLI engine instead. No key ever leaves your machine except to the provider you chose.
    3. 
      
  3. Create your first bot
    In Bots, pick a specialist (Coder, Scout, Reviewer…) or craft your own with a persona and per-bot tool policy. Chat with it in Chat — tool calls that need a human pause for an inline approval card.
    4. 
      
  4. Run a workflow
    Open Workflows, run a built-in flow (try Morning briefing), or import your n8n JSON — common nodes map automatically. Bots can trigger workflows from chat, and workflows can call a bot turn as a node.
    5. 
      
  5. Pair the Android app
    On desktop, open the companion panel to show the pairing QR code; scan it in the Android app. On your LAN it pairs directly; with KRIYADOT_PUBLIC_URL set, it pairs over HTTPS from anywhere.
    6. 
      
  6. Make it yours
    Preferences holds five themes (light, dark, midnight, porcelain, ocean), Simple/Pro modes, English + Hindi UI, voice notes, and your pet picker — six 3D companions to choose from.
    7.

Why one platform for agents
